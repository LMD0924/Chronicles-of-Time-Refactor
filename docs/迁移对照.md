## 四、技术栈变化

| 项 | 老项目 | 新项目 |
|---|---|---|
| 运行形态 | 多服务独立端口（8081/8082/8090/8091/8092/8500） | 单启动类 8080（Cloud 依赖保留但默认关闭） |
| 建表 | 手工 SQL / 无版本管理 | Flyway V1/V2 自动迁移 |
| ORM | MyBatis-Plus | MyBatis-Plus（沿用） |
| UI 组件库 | Element Plus、Ant Design Vue、Cesium、three | 纯 Tailwind 原生组件 + ECharts 5（3D 图谱改关系图） |
| 前端构建 | Vite 7 / Vue 3.5 | Vite 5 / Vue 3.4（对齐参考项目） |
| 认证 | jjwt + Redis | 纯 JDK HS256 JWT + PBKDF2 + token_version |
| 文档 | 仅一个 13 字节 README | README + 8 篇设计文档 |
