# 路线图

## P0（已完成）· 重构基线

- 混合 DDD 模块化单体、11 个平铺模块、唯一 launcher、单端口 8080
- MyBatis-Plus + MySQL 单库 + Flyway V1/V2
- 双身份（USER / ADMIN）共用同一前端、三级路径鉴权、审计
- 55 个前端页面，功能点全量保留
- 拾光时间线跨域聚合、悬停 Mega Menu、时间轴卷轴过渡
- 与 AdmitAtlas 一致的视觉体系（纸面磨砂、彩色描边、手写体、双主题、动效）

## P1（已完成）· 工程验证

- `mvn -B clean package` 全模块编译与单元测试
- `npm run build` 前端生产构建
- 统一资源 CRUD、领域特性接口、系统探针
- README + 8 篇设计文档 + 迁移对照

## P2（演进目标）

- 真实数据采集与审核发布、数据版本化
- Redis 缓存（热点字典、会话辅助）、Elasticsearch 全文检索
- 异步任务队列（批量模拟、图谱计算）
- Nacos 注册发现 + Spring Cloud Gateway 独立网关（当前依赖保留但关闭）
- 菜单级细粒度权限（当前仅 USER / ADMIN 两档）

## P3（远景）

- 按限界上下文拆分为独立微服务（给目标模块补启动类与配置即可）
- MinIO 对象存储替换本地文件、CDN 加速
- Prometheus / SkyWalking 可观测性
- 移动端手势、多语言、高对比度模式
- 后端原生 PDF 导出、方案只读分享令牌

## 明确未做

- 真实外部数据源接入（当前为演示数据）
- 手机号验证码登录、第三方 OAuth
- 大模型内容生成（全部为本地规则推演）
