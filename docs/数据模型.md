# 数据模型

单库 `chronicles_of_time`，43 张业务表。表名**沿用老项目**，保证已有数据可迁移；
Java 实体与前端字段使用 camelCase，通过 MyBatis-Plus 的 `map-underscore-to-camel-case` 映射。

## 通用约定

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT AUTO_INCREMENT | 主键 |
| `user_id` | BIGINT | 业务表通用，按账号隔离（字典类表无此列） |
| `created_at` | VARCHAR(64) | 创建时间字符串 `yyyy-MM-dd HH:mm:ss` |
| 布尔列 | TINYINT(1) | `is_*` / `*ed` / `done` / `active` |
| 长文本列 | TEXT | `content` / `body` / `description` / `note` / `options_json` 等 |

## planning（17 张）

`subject_option`、`subject_combination`、`course_selection`、`selection_intention`、
`course_guidance`、`selection_history`、`grading_scale`、`major_requirement`、
`volunteer_plan`、`volunteer_detail`、`admission_simulation`、`term_course`、
`graduation_gap`、`review_plan`、`target_path`、`quality_record`、`checklist_item`。

关键字段：`volunteer_detail` 含 `plan_id / priority / chance_level(冲稳保) / score_line`；
`term_course` 含 `term / credit / score / gpa_point`；`grading_scale` 含 `level / min_score / max_score / ratio`。

## archive

`certificate`、`paper`、`paper_suggestion`、`course_tree_node`（`parent_id` 自关联）、
`thesis_board_item`、`elective_post`。

## community

`content`（含 view_count / like_count / favorite_count / status / tags）、
`content_comment`、`like_record`、`favorite_record`。

## 索引建议

`V1__schema.sql` 只建表，不建二级索引（保证 MySQL 与 H2 都能直接执行）。
生产环境的按 `user_id` 索引脚本见 `back-end-spring-cloud/sql/indexes.sql`。

## 数据版本与合规

- 演示数据由 `V2__seed_demo.sql` 写入，账号密码以 PBKDF2 哈希存储，页面不回显 `password_hash`（`@JsonIgnore`）。
- 业务数据按账号隔离；管理员 `all=true` 仅用于后台核查，操作写入 `audit_log`。
- 上传文件落在 `COT_UPLOAD_DIR`（默认 `./uploads`），按 `年/月/日` 分目录，随机文件名。
