# 接口说明

## 一、统一约定

- 前缀 `/api/v1`，JSON 请求 / 响应。
- 响应包装：`{ code, message, data, timestamp }`，`code=200` 表示成功。
- 鉴权：`Authorization: Bearer <token>`；公开路径见下表。
- 业务资源默认按当前账号隔离；管理员可加 `all=true` 跨账号核查。
- 未登记路径是真正的 404，不会被鉴权层改成 401。

## 二、权限矩阵

| 路径 | 游客 | 用户 | 管理员 |
|---|---|---|---|
| `/api/v1/auth/login`、`/register`、`/verify` | ✅ | ✅ | ✅ |
| `/api/v1/system/*`、`/api/v1/dashboard` | ✅ | ✅ | ✅ |
| GET `/api/v1/community/contents*`、知识图谱 / 标签云 / 分类统计 / 相关文章 | ✅ | ✅ | ✅ |
| GET `/api/v1/planning/subject-options`、`subject-combinations`、`major-requirements`、`grading-scales` | ✅ | ✅ | ✅ |
| GET `/api/v1/timeline/share` | ✅ | ✅ | ✅ |
| 其余 `/api/v1/*` 读写（含 `GET /api/v1/timeline/feed`） | ❌ 401 | ✅ | ✅ |
| `/api/v1/admin/*` | ❌ | ❌ 403 | ✅ |

## 三、统一资源接口

对任意上下文 `<ctx>` 与资源 `<res>`：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/<ctx>/r` | 列出该上下文全部资源名 |
| GET | `/api/v1/<ctx>/r/meta/stats` | 各资源计数 |
| GET | `/api/v1/<ctx>/r/<res>?keyword=&all=false` | 列表 |
| GET | `/api/v1/<ctx>/r/<res>/<id>` | 详情 |
| POST | `/api/v1/<ctx>/r/<res>` | 新增（服务端写入 `user_id`） |
| PUT | `/api/v1/<ctx>/r/<res>/<id>` | 修改 |
| DELETE | `/api/v1/<ctx>/r/<res>/<id>` | 删除 |
| POST | `/api/v1/<ctx>/r/<res>/batch-delete` | 批量删除，body 为 id 数组 |

`<ctx>` 取值：`identity / timeline / learning / planning / archive / community`。
资源名对照见 `docs/迁移对照.md` 与 `back-end-spring-cloud/docs/后端模块总览.md`。

## 四、领域特性接口

| 分组 | 端点 |
|---|---|
| 认证 | POST `/auth/login` `/auth/register` `/auth/logout`；GET `/auth/verify` |
| 个人中心 | GET/PUT `/profile`；POST `/profile/password`；GET `/profile/overview` |
| 管理 | GET/POST `/admin/users`；PUT `/admin/users/{id}`；POST `/admin/users/{id}/reset-password`；GET `/admin/audit` `/admin/stats` |
| 时间线 | GET `/timeline/feed?type=&all=false`（跨域聚合）、`/timeline/stats`、`/timeline/trend`、`/timeline/milestones`、`/timeline/connections`；POST `/timeline/connections` |
| 学习 | GET `/learning/knowledge-graph`、`/learning/heatmap`、`/learning/path`、`/learning/weak-subjects`、`/learning/trend`、`/learning/radar`、`/learning/random-questions`；POST `/learning/practice/submit` |
| 规划 | GET `/planning/subjects`、`/combinations/hot`、`/selection/statistics`、`/volunteer/report/{id}`、`/gap-analysis`、`/schedule`、`/compare`；POST `/selection/recommend`、`/selection/confirm`、`/volunteer/recommend`、`/volunteer/simulate`、`/gpa/simulate` |
| 档案 | GET `/archive/resume/complete`、`/archive/paper/suggestions`、`/archive/course-tree`、`/archive/stats` |
| 社区 | GET `/community/contents/hot`、`/contents/search`、`/contents/{id}/detail`、`/knowledge-graph`、`/tag-cloud`、`/category-stats`、`/related`；POST/DELETE `/community/contents/{id}/like`、`/favorite` |
| 文件 | POST `/files/image`、`/files/file`、`/files/files`；DELETE `/files/{id}`；静态访问 `/files/**` |
| 系统 | GET `/system/health`、`/system/modules`、`/system/overview`、`/dashboard` |

`GET /timeline/feed` 需登录：`type` 按节点类型过滤；私有节点（记录、里程碑、工作、进阶、
成绩、练习、规划、目标、证书、论文）只返回当前账号的数据，社区已发布文章为公开内容、所有登录用户可见；
`all=true` 仅对管理员生效，用于跨账号核查，普通用户传该参数会被忽略。

## 五、错误码

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数有误 |
| 401 | 未登录 / 登录失效 / 密码错误（含剩余次数） |
| 403 | 无权访问 / 账号停用 |
| 404 | 资源不存在 |
| 409 | 资源冲突（如账号已存在） |
| 423 | 账号冻结（连续失败 5 次） |
| 500 | 服务内部错误 |

前端 Axios 统一解包 `data`，401/403（登录接口除外）清理本地会话并广播 `cot:unauthorized`。
