# 前端视觉规范

> 单一事实来源：`front-end/src/style.css` 与 `tailwind.config.js`。
> 视觉与 `AdmitAtlas` 完全一致；**唯一不同是路由过渡**。

## 一、设计基线

| 项 | 取值 |
|---|---|
| 风格 | 轻盈「纸面」+ 磨砂玻璃：极浅冷白渐变底、半透明磨砂卡片 + 1px 细边、极轻阴影、大留白 |
| 强调色 | 明亮蓝 `#4a6cf7`（浅）/ `#7f9dff`（暗） |
| 底 | 浅色 `#f8f9fd`，暗色 `#0f121a` |
| 辅助色 | 薄荷绿 / 天蓝 / 淡紫 / 琥珀 / 陶红 / 青，用于彩色描边按钮、小胶囊、圆形指标 |
| 字体 | 正文系统中文栈；展示标题用本地手写体 Ma Shan Zheng（26 KB 子集） |
| 圆角 | 卡片 14px、小卡 12px、控件 9~10px、胶囊 999px |
| 布局 | 非对称 `grid-cols-12`；首页为居中窄栏 Hero + 下方卡片区 |

按钮沿用**彩色描边**：极浅同色底 + 同色 1px 边框 + 同色文字与图标，
`.btn-blue / mint / violet / amber / rose / teal / slate` 一色一义；只有弹窗最终确认保留 `.btn-solid`。

## 二、双主题

`<html data-theme="light|dark">` 驱动，所有颜色走 CSS 变量；
`index.html` 首屏内联脚本防闪烁；默认浅色，偏好存 `localStorage['cot-theme']`；
切换时全站 `background-color / color` 有 0.55s 过渡。

## 三、动效体系

只动画 `transform / opacity / filter`；`prefers-reduced-motion: reduce` 时统一关闭。

| 类别 | 实现 |
|---|---|
| 环境 | 3 个极淡光斑缓慢漂移 |
| 标题 | `.hand-title` 墨迹式 clip-path 揭示 1.25s；首页打字机 95ms/字 |
| 入场 | `v-reveal="n"` 基于 IntersectionObserver，淡入 + 上移 16px |
| 数字 | `v-count` 进入视口三次方缓出计数；进度条宽度生长 |
| Hover | `.lift` 上浮、`.spotlight` 跟随光、彩色按钮上浮 2px、箭头位移 |
| 微动 | `float`、`pulse-dot`、`shimmer`、`icon-swap` |
| 触感 | 所有 `.btn` 按下 `scale(.97)` |

## 四、导航栏与布局（本项目调整）

- 顶部胶囊导航**样式与参考项目完全一致**：置顶 `scrollY <= 28` 时 72px 全透明融入页面；
  下滑后收缩为 56px、1040px 宽的磨砂胶囊（blur(20px) + 细边 + 阴影）。
- **菜单过多时悬停弹出 Mega Menu 大面板**：`.mega-wrap:hover .mega-panel`，
  3 列网格，每项含名称与一行说明，共 5 组（时间线 / 学习 / 规划 / 社区 / 档案）。
- 管理员入口在同一导航右侧，用户态显示身份胶囊、头像、昵称、设置与退出。
- 首页改为手写体 Hero + 打字机 + 4 个彩色圆形指标 + 时间线预览 + 功能宫格；
  内页统一「页头 eyebrow + 工具条 + 磨砂内容卡」。

## 五、路由切换过渡（唯一不同：时间轴卷轴）

参考项目是「半透明磨砂 HUD 遮罩 + 网格 + 扫描光带 + 四角准星」，
本项目**完全移除 HUD 遮罩**，改为：

1. `router.beforeEach` 递增 `seamKey`，`DefaultLayout` 在页面进入时重建 `.timeline-seam`，
   沿内容区左侧掠过一条 2px 时间轴脊线（渐变 + 节点，0.72s）。
2. `<Transition name="page" mode="out-in">`：
   - 离场 0.38s：`translateX(-42px) + rotateY(6deg) + scale(.99) + blur(7px) + opacity 0`，纸页向左卷起。
   - 入场 0.52s：自 `translateX(52px) + rotateY(-8deg) + scale(.986) + blur(9px)` 归位，从右侧沿时间轴展开。
3. 全部只动画 `transform / opacity / filter`；`prefers-reduced-motion` 下隐藏脊线、去掉模糊与位移。

实现位置：`composables/useTimelineTransition.js`、`layouts/DefaultLayout.vue`、`style.css` 的 `.page-*` / `.timeline-seam`。

## 六、验证口径

| 检查项 | 期望 |
|---|---|
| 默认主题 | `html[data-theme=light]`，body 背景 `rgb(248,249,253)` |
| 导航收缩 | 置顶 72px 透明；滚动后 56px 圆角胶囊带 blur |
| Mega Menu | 悬停总菜单出现 3 列大面板，含全部子入口 |
| 路由过渡 | 跳转瞬间 `.timeline-seam` 存在、旧页左卷新页右展，**不存在** `.route-loader` / `.hud-*` 遮罩 |
| 按钮颜色 | 任一 `.btn` 的 `color === border-color`，同组至少 2 种色调 |
| 磨砂玻璃 | `.glass` 背景 alpha < 1 且 `backdrop-filter` 含 blur |
| 手写体 | `document.fonts.check('40px "Ma Shan Zheng"')` 为 true |
| 构建 | `npm run build` 通过，产物含字体，无硬编码旧配色类 |
