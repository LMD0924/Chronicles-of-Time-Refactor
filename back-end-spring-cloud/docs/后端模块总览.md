# 后端模块总览

后端位于 `back-end-spring-cloud/`，父 POM 在此目录下，11 个模块全部平铺（Reactor 共 12 个工程）。

## 运行形态：混合 DDD 模块化单体

| 角色 | 模块数 | 特征 |
|---|---|---|
| 普通 library jar | 10 | 无 `main`、无独立 `application.yml`、不应用 `spring-boot-maven-plugin` |
| 可执行应用 | 1（`launcher`） | 唯一 `CotApplication`、唯一配置、唯一可执行 jar、端口 8080 |

每个业务模块内部严格四层：

```
<context>/
├── interfaces/          # REST 控制器（统一资源接口 + 领域特性接口）
├── application/         # 应用服务：编排、账号隔离、关键词过滤、统计
├── domain/
│   ├── model/           # 领域实体 / 持久化模型（@TableName）
│   └── repository/      # 仓储接口（依赖倒置）
└── infrastructure/
    └── persistence/     # MyBatis-Plus Mapper + 仓储实现
```

依赖方向：`launcher → 各业务模块 → api → common-core`，业务模块之间不直接互相依赖，统一通过 `AuthContext` 取当前用户。Spring Cloud 依赖保留但默认关闭，未来拆分微服务只需给目标模块补回启动类与配置。

## 统一资源接口

所有业务实体共用同一套 REST 约定，前端只需一个 `api` 封装：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/<context>/r` | 列出该上下文全部资源名 |
| GET | `/api/v1/<context>/r/meta/stats` | 各资源计数 |
| GET | `/api/v1/<context>/r/{resource}?keyword=&all=false` | 列表（默认按当前账号隔离，管理员可 `all=true`） |
| GET | `/api/v1/<context>/r/{resource}/{id}` | 详情 |
| POST | `/api/v1/<context>/r/{resource}` | 新增（服务端自动写入 `user_id`） |
| PUT | `/api/v1/<context>/r/{resource}/{id}` | 修改 |
| DELETE | `/api/v1/<context>/r/{resource}/{id}` | 删除 |
| POST | `/api/v1/<context>/r/{resource}/batch-delete` | 批量删除 |

领域特性接口（登录、时间线聚合、知识图谱、志愿模拟、简历聚合、内容互动、审计等）挂在各上下文的根路径 `/api/v1/<context>/...`，见 `docs/接口说明.md`。

## 启动与验证

```bash
cd back-end-spring-cloud
mvn -B clean package
java -jar launcher/target/cot-launcher-0.1.0-SNAPSHOT.jar --spring.profiles.active=dev   # H2 零依赖演示
java -jar launcher/target/cot-launcher-0.1.0-SNAPSHOT.jar                                # MySQL 8（默认）
curl http://localhost:8080/api/v1/system/modules
```

MySQL 连接串 / 账号 / 密码走 `COT_DB_URL` / `COT_DB_USER` / `COT_DB_PASSWORD`；JWT 密钥走 `COT_AUTH_SECRET`。
